1. ¿Qué es una rama (branch) en Git y para qué sirve?

Una rama en Git es una línea de desarrollo independiente que permite trabajar en nuevas funcionalidades o cambios sin afectar la rama principal.

2. ¿Cómo se crea y se cambia entre ramas en Git?

Se crea con git branch nombre_rama y se cambia con git checkout nombre_rama.

3. ¿Cuál es la diferencia entre la rama main y otras ramas?

La rama main es la principal y contiene la versión estable del proyecto.

4. ¿Cómo se combinan ramas en Git (merge)?

Se usa git merge para unir ramas.

5. ¿Qué problemas pueden ocurrir y cómo se resuelven?

Conflictos, que se solucionan editando manualmente los archivos.
